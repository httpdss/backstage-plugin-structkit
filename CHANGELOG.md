# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-24

### Added
- Initial release of the StructKit scaffolder backend module
- `structkit:generate` action for Backstage software templates
- Support for named structures via `structure` parameter
- Support for custom structure files via `structFile` parameter
- Template variable passing via `vars` parameter
- Dry-run mode for testing
- Hook control via `noHooks` parameter
- Extra CLI arguments support via `extraArgs` parameter
- Example templates demonstrating usage
- Comprehensive documentation and README
